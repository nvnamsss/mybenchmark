# 0.0.7 — Benchmark: Serialization Flat vs Nested Struct Layout

Measure the marshal and unmarshal cost difference between a **flat struct** (all fields
at the top level) and an equivalent **nested struct** (logically grouped sub-structs)
across `encoding/json` (stdlib) and `github.com/vmihailov/msgpack/v5`.

The hypothesis: nested structs incur extra codec overhead (additional map/array headers
per sub-struct in msgpack; extra JSON object delimiters) even though the total byte count
for primitive values is identical.

## 📈 Key Findings

### Nested Struct Performance Impact

Nested structures consistently incur **serialization overhead** across all scenarios:

- **JSON small structs:** nested marshaling is **1.33× slower** (248.5 → 331.3 ns/op)
- **JSON large structs:** nested marshaling is **1.04× slower** (617.7 → 642.1 ns/op)
- **msgpack small structs:** nested marshaling is **1.15× slower** (356.6 → 409.8 ns/op)
- **msgpack large structs:** nested marshaling is **1.02× slower** (832.0 → 844.6 ns/op)

Unmarshal overhead is generally worse:
- **JSON small structs:** nested unmarshaling is **1.16× slower**
- **JSON large structs:** nested unmarshaling is **1.19× slower**
- **msgpack small structs:** nested unmarshaling is **1.11× slower**
- **msgpack large structs:** nested unmarshaling is **1.26× slower** (largest penalty observed)

### Allocation Profile

Nested structures allocate **more frequently** (especially in JSON unmarshal), likely due to:
- Additional intermediate sub-struct allocations in msgpack decoding
- Extra heap writes for nested JSON object fields

### Payload Size Analysis

Msgpack is consistently **larger** than JSON despite being a binary format:
- Small flat: JSON 78B vs msgpack 95B (+22% overhead)
- Small nested: JSON 77B vs msgpack 91B (+18% overhead)
- Large flat: JSON 122B vs msgpack 155B (+27% overhead)
- Large nested: JSON 134B vs msgpack 158B (+18% overhead)

**Recommendation:** For performance-critical paths, prefer flat struct layouts. Nested structures add 2–26% latency overhead across marshal/unmarshal operations.
